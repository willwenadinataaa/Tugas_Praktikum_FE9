# Senja Coffee

Website company profile kedai kopi dengan Next.js App Router.

## Menjalankan secara lokal

```bash
npm install
npm run dev
```

Buka `http://localhost:3000`. Halaman yang tersedia: Beranda, Menu, detail menu dinamis (`/menu/[slug]`), Cerita kami, dan Kontak.

Konten minuman dikelola di `data/menu.js`; komponen navigasi, footer, kartu minuman, dan formulir berada di `components/`.
